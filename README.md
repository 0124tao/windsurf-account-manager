# Windsurf Account Manager

A cross-platform desktop tool for managing Windsurf accounts (Windows / macOS / Linux).

## Download

Get the latest installer from the [**Releases**](https://github.com/0124tao/windsurf-account-manager/releases/latest) page.

| Platform | Files |
| --- | --- |
| Windows x64 / ARM64 | `.exe` (NSIS) / `.msi` |
| macOS Intel / Apple Silicon | `.dmg` |
| Linux x64 | `.deb` / `.rpm` / `.AppImage` |
| Linux ARM64 | `.deb` / `.rpm` |

## Auto-Update

The app includes a built-in updater. New versions will be detected and installed automatically.
